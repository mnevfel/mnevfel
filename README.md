## How I build

- **Boundaries before features.** Decide where the seams go before the first screen exists. Features are cheap to move; boundaries are not.
- **The smallest complete thing.** Every endpoint, setting and dependency is a promise to maintain.
- **Agents draft, I decide.** The brief, the architecture, the review and the release decision stay with me.
- **Observable before done.** Metrics, logs and a rollback path ship with the feature.
